# Topic Backlog

A standing picklist of subtopics, organized under the **5 top-performing proven
topics** (from the production performance data in `CLAUDE.md`) rather than the
abstract `topic_cluster` buckets. Each proven topic gets 5 subtopic variations
that extend or riff on what already worked, so a render session picks from
here instead of free-picking or re-deriving ideas from scratch.

Pass the chosen title as context/wording into `main.py --topic "..."`
(script_gen still writes the actual hook/script itself under all normal
brand/gate rules — these are angle seeds, not finished hooks).

**Workflow:** pick an `[ ]` item, generate the script, then flip it to `[x]`
and add the render date + title once the script is actually generated (not
just discussed). Never re-suggest a `[x]` item.
